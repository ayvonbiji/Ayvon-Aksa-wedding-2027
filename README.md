# Ayvon & Aksa — Wedding Invitation

A digital wedding invitation and website for **Ayvon Joseph Biji & Aksa Saji Kunnel**
— Monday, 23 August 2027 · 11:30 AM IST · St. Thomas Valiyapally, Ranni, Kerala, India.

**Live site:** https://ayvonbiji.github.io/Ayvon-Aksa-wedding-2027/

Built with Vite + React + TypeScript. No database, no login, no analytics, no tracking,
no API keys. Deployed automatically to GitHub Pages on every push to `main`.

---

## Quick start

```bash
npm install          # once
npm run dev          # local preview → http://localhost:5173/Ayvon-Aksa-wedding-2027/
npm test             # unit tests (dates, countdown, calendar file, content)
npm run build        # regenerates logos/QR/social image, then builds to /dist
npm run preview      # serve the production build locally
```

Requires Node.js 22.6 or newer.

**Deploying:** push to `main`. The workflow in `.github/workflows/deploy.yml` tests,
builds and publishes the site. (One-time setup: GitHub → repository **Settings → Pages →
Source: GitHub Actions**.)

## Where to change things

| What | File |
| --- | --- |
| Names, date, time, venue, map link, site URL, messages, music, petals | `src/config/wedding.ts` |
| Love story chapters | `src/content/story.ts` |
| Gallery photos | `src/content/gallery.ts` |
| Logo artwork (code) | `scripts/logo-art.mjs`, `src/art/ornaments.js` |
| Logo / favicon / social image / QR generator | `scripts/build-assets.mjs` |
| Page title, description, social tags | `src/config/wedding.ts` → `meta` (injected into `index.html` at build) |
| Colours, fonts, spacing | top of `src/styles/global.css` |

### Your love story

Open `src/content/story.ts`. Each chapter is one `{ … }` block in the `chapters` list:

```ts
{
  title: 'The Coffee Date',
  date: 'June 2024',            // optional
  place: 'Kochi',               // optional
  text: ['First paragraph.', 'Second paragraph.'],
  note: 'A short line in script', // optional
  image: 'images/story/coffee.webp', // optional, under /public
  imageAlt: 'Ayvon and Aksa at the café',
  caption: 'Where it all began', // optional
},
```

Add, delete or move blocks to add, remove or reorder chapters. Set `chapters: []` to
show the "Our story is waiting to be told" placeholder instead.
The illustrated comic is shown as a keepsake card — change or hide it with `illustration`.

### Gallery photos

1. Put your originals in a `photos/` folder at the project root (it is git-ignored, so
   originals never get published).
2. Run `npm run images` — optimised `.webp` files (1600 px + 800 px thumbnails, metadata
   and GPS stripped) appear in `public/images/gallery/`. Sideways photo?
   `npm run images -- --rotate=photo-name:90`
3. Add an entry to `src/content/gallery.ts`:

```ts
{
  src: 'images/gallery/beach.webp',
  thumb: 'images/gallery/beach-thumb.webp',
  alt: 'Ayvon and Aksa walking on the beach at sunset',
  caption: 'Golden hour',
  orientation: 'landscape',   // 'portrait' | 'landscape' | 'square'
  position: '50% 30%',        // adjust the crop (horizontal% vertical%)
},
```

A full `https://` image URL also works for `src`. Missing images show an ornamental
placeholder instead of a broken icon.

**Hero photo:** `wedding.hero.photo` in `src/config/wedding.ts`.
**Wedding-day photo** (shown after the ceremony): `wedding.countdown.afterPhoto`.

## Public URL, social preview & QR code

The public address lives in **one place**: `siteUrl` in `src/config/wedding.ts`
(currently `https://ayvonbiji.github.io/Ayvon-Aksa-wedding-2027/`).

It drives the canonical link, Open Graph/Twitter tags, the WhatsApp message, the
calendar event, the base path of the build, and the QR code.

**If you move to a custom domain** (e.g. `https://ayvonandaksa.com/`):
1. Change `siteUrl` (keep the trailing `/`).
2. Run `npm run assets` (or just `npm run build`) — this regenerates
   `public/qr/wedding-qr.png` / `.svg` and `public/og-image.png`.
3. Commit and push. Print the new QR code — **an old printed QR keeps pointing at the old
   address**, so only print once the final URL is settled.

The QR code shown on the website is always generated live from `siteUrl`; the downloadable
files come from `npm run assets`. Both use error-correction level H with the monogram in
the centre (≈4% of the area) and a 4-module quiet zone.

**Social image:** `public/og-image.png` (1200 × 630). It is generated by
`npm run assets`; to use your own image, replace the file (same name, or change
`meta.ogImage`). WhatsApp/Facebook cache previews — use
[Facebook's Sharing Debugger](https://developers.facebook.com/tools/debug/) to refresh.

## Testing the countdown & calendar

* `npm test` checks that 23 Aug 2027 11:30 IST = 06:00 UTC, that the countdown never goes
  negative, that the `.ics` file has a single event in `Asia/Kolkata`, and that no other
  event types appear anywhere in the source.
* **Preview any moment** by adding `?now=` to the URL (use `%2B` for `+`):
  * After the wedding: `…/?now=2027-08-23T11:31:00%2B05:30`
  * One minute before: `…/?now=2027-08-23T11:29:00%2B05:30`
* **Calendar:** "Apple / Outlook (.ics)" downloads `ayvon-aksa-wedding.ics`
  (11:30–13:30 IST with a reminder the day before). Change the length with
  `ceremony.durationMinutes`. "Google Calendar" opens a pre-filled event.

## Features

Animated gate-fold invitation cover · interlaced A&A monogram and wordmark · hero with
names, date cartouche and arched couple photo · live countdown (Asia/Kolkata) that turns
into *"Today, our forever began."* after the ceremony · Our Wedding Day card with
Google Maps directions and calendar (.ics + Google) · Bible verse (Mark 10:9, KJV) ·
love-story timeline · framed slideshow + photo grid + full-screen lightbox (arrows,
keyboard, Escape, swipe) · Dear Guest note · WhatsApp / native share / copy link ·
QR code with PNG & SVG download · optional music (off by default) · sticky navigation
with active section · back-to-top · falling petals · reduced-motion support throughout.

**Music:** `public/audio/canon-in-d-music-box.mp3` is an original synthesised music-box
arrangement of Pachelbel's Canon in D (public-domain composition), created for this
site by `scripts/make-music.py`, so it is free to use. Swap in any track you have a
licence for via `wedding.music.src`, or set `music.enabled: false`.

**Venue map:** no verified coordinates for St. Thomas Valiyapally were available, so
"Get Directions" uses a Google Maps place search. For a pin-exact link, open the church
in Google Maps → Share → Copy link, and paste it into `ceremony.mapsUrl`.
